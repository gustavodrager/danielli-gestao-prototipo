# Danielli Gestão — Protótipo UX/UI

Protótipo navegável mobile-first para validação da experiência gerencial do Restaurante e Doceria Danielli.

## Escopo atual
- Dashboard gerencial com dados simulados
- Drill-down de faturamento, CMV e resultado
- Visão de unidades de negócio pelas cores das comandas
- Caixa e histórico
- Fluxo inicial de fechamento de caixa
- Conferência

> Os valores exibidos são fictícios e servem apenas para validação de UX/UI.

## Executar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Sem backend e sem persistência nesta fase.
